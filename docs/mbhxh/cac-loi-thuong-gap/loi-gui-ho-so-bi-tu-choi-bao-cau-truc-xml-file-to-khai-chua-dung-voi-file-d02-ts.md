# **BHXH VN trả về lỗi “Cấu trúc XML file tờ khai chưa đúng với file D02-TS.xsd,...”**

???+ Bug "Mô tải lỗi"

    BHXH VN trả về lỗi “Cấu trúc XML file tờ khai chưa đúng với file D02-TS.xsd : Line: 39, Position: 8 “The ‘TienLuong’ element is invalid – The value ” is invalid according to its datatype ‘Decimal’ – The string ” is not a valid Decimal value.”

    Nguyên nhân:

    Do lỗi nhập dữ liệu “hệ số lương/ mức lương”

### **Bước 1: Vào hồ sơ đã kê khai trên phần mềm mBHXH >> kiểm tra cột “Hệ số/ mức lương”. Nếu ko nhập tiền hoặc hệ số vào đó thì phải nhập số 0 vào đó >> sau đó ghi lại thông tin.**
