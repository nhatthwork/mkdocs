# **Gửi hồ sơ bị từ chối báo: Cấu trúc XML file tờ khai chưa đúng với file https://gddt.baohiemxahoi.gov.vn/XMLSchema/TK1-TS/TK1-TS.xsd ,...”**

???+ Bug "Mô tải lỗi"

    Gửi hồ sơ bị từ chối báo: Cấu trúc XML file tờ khai chưa đúng với file https://gddt.baohiemxahoi.gov.vn/XMLSchema/TK1-TS/TK1-TS.xsd : Line: 12, Position: 23 “The ‘Mahuyen_KS’ element is invalid – The value ’11’ is invalid according to its datatype ‘String’ – The Enumeration constraint failed.”

    Nguyên nhân:

    Do dữ liệu thông tin phần “tỉnh/huyện/xã/ bệnh viện” khai sinh hoặc địa chỉ nhận hồ sơ trên tờ khai đang nhập sai dữ liệu do lấy dữ liệu từ HSNS là dữ liệu cũ sang.

### **Bước 1: Vào lại phần tờ khai kê khai hoặc thông tin người lao động >> tìm đến các cột Tỉnh/huyện/xã  khai sinh, tỉnh /huyện/xã nhận hồ sơ, bênh viện >> sau đó chọn lại dữ liệu >> lưu lại**
