# **QUẢN LÝ DANH SÁCH CHỮ KÝ**

### **Bước 1: Nhấn vào trang cá nhân, chọn cài đặt**

![Hình 1](../../assets/images/mEcontract/mEcontract-chu-ky-1.png "Hãy bấm vào để xem rõ hơn")

### **Bước 2: Trong phần “Chữ ký của tôi”, hệ thống hiển thị các loại chữ ký:  Chữ ký hình ảnh , Chữ ký HSM Digital , Chữ ký USB Token, Chữ ký file CA**

![Hình 1](../../assets/images/mEcontract/mEcontract-chu-ky-2.png "Hãy bấm vào để xem rõ hơn")

### **Bước 3: Bấm nút “+ Thêm chữ ký”.**

![Hình 1](../../assets/images/mEcontract/mEcontract-chu-ky-3.png "Hãy bấm vào để xem rõ hơn")

### **Bước 4: Chọn loại chữ ký cần thêm:**

#### **Chữ ký hình ảnh:** Tải ảnh chữ ký hoặc vẽ chữ ký trực tiếp trên màn hình.

![Hình 1](../../assets/images/mEcontract/mEcontract-chu-ky-4.png "Hãy bấm vào để xem rõ hơn")

#### **Chữ ký HSM Digital:** Nhập tài khoản, mật khẩu , PIN Code rồi lưu chữ ký.(có thể thay đổi tên chữ ký để dễ phân biệt)

![Hình 1](../../assets/images/mEcontract/mEcontract-chu-ky-5.png "Hãy bấm vào để xem rõ hơn")

#### **Chữ ký USB token**

**B1:**  Mở plugin minvoice 1.0
 
(Nếu chưa có plugin minvoice 1.0 vui lòng tải tại link: https://cks.minvoicehcm.com.vn/tai-cong-cu-ho-tro để tải về)

![Hình 1](../../assets/images/mEcontract/mEcontract-chu-ky-6.png "Hãy bấm vào để xem rõ hơn")

**B2:**  Cắm USB xong sẽ hiện thông tin token từ USB rồi lưu chữ ký

![Hình 1](../../assets/images/mEcontract/mEcontract-chu-ky-7.png "Hãy bấm vào để xem rõ hơn")

#### **Chữ ký file CA:** Nhập Tên chữ ký, File chứng thư (P12 hoặc PFX), nhập mật khẩu file P12/PFX

![Hình 1](../../assets/images/mEcontract/mEcontract-chu-ky-8.png "Hãy bấm vào để xem rõ hơn")

### **Bước 5: Sau khi lưu chữ ký thành công sẽ hiển thị thông tin chữ ký**

![Hình 1](../../assets/images/mEcontract/mEcontract-chu-ky-9.png "Hãy bấm vào để xem rõ hơn")

Sau khi cập nhật mật khẩu thành công, người dùng quay lại màn hình đăng nhập và đăng nhập bằng **mật khẩu mới.**

???+ info "Xin chân thành cảm ơn quý khách hàng đã tin dùng sản phẩm của M-Invoice"

    Có bất kỳ vướng mắc nào trong quá trình sử dụng hãy liên hệ với M-Invoice tại mục Hỗ trợ kỹ thuật góc phải bên dưới màn hình hoặc gọi tổng đài kỹ thuật của M-Invoice (1900.955.557 Nhánh 1)
